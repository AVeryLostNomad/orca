# Unity

This discovery stub loads the version-matched guide from the Orca executable used for this session.

In a Unity project, drive the running Unity Editor with the `unity` CLI instead of hand-editing
scene, prefab, asset, or `.meta` files, and pass `--project-path` on every Editor command. The
Unity CLI's own guide, `unity skill show`, is authoritative for `unity` commands and flags.
